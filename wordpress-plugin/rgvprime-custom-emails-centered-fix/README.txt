RGVPRIME Custom Woo Emails
==========================

Install:
1. Go to WordPress Admin > Plugins > Add New > Upload Plugin.
2. Upload rgvprime-custom-emails.zip.
3. Activate "RGVPRIME Custom Woo Emails".
4. Go to WooCommerce > Settings > Emails and make sure email type is HTML.
5. Send a test order email.

This plugin overrides WooCommerce email templates from its own templates/emails folder and applies the RGVPRIME storefront hero system to transactional emails. The hero remains dark and branded while the content automatically adapts to light or dark mode.

Version 2.0.0 includes:
- Hero-driven order, account and administrative WooCommerce templates.
- Light and dark color-scheme support with explicit email-client fallbacks.
- Responsive order progress, product, totals, address and tracking sections.
- Consistent sender identity and research-use footer.
