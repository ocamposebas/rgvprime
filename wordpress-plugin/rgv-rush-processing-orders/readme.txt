Highlights paid Rush Processing orders in WooCommerce admin.

== Description ==

Adds a Rush column and colored badges to both HPOS and classic WooCommerce
order lists. Paid rush orders receive an orange row highlight and a prominent
banner inside the order. Rush requests awaiting payment are shown in yellow.

The plugin recognizes the `_rgv_priority_processing` order meta created by the
RGV checkout and existing fee lines containing Priority Processing, Rush
Processing, or Skip the Line.
